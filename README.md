# עיר הסוחרים
עיר מסחר איזומטרית בעברית עם משרד תרגול MNQ ודסק ETH בחשבון Bybit Demo. תרגול MNQ מבוסס על נתונים סינתטיים. דסק ETH פועל על מחירי ספוט ציבוריים ובודק הוראות מול הבורסה בחשבון הדמו.

## הפעלה
עם Node.js 22 ומעלה, הריצו בתיקייה `node server.mjs` ופתחו http://127.0.0.1:4173. אין תלויות להתקנה. לבדיקות הריצו `node --test`.

לחצו על הפעלה. כאשר מופיעה הצעה לחצו על אישור הצעה והמשיכו בהפעלה. לחיצה על עסקה מציגה את מסלול ההחלטה והביצועים. עצירת חירום שומרת את הפוזיציה הפתוחה ומבטלת את יתרת ההוראה המדומה. יום חדש שומר עותק מהיום הקודם בדפדפן. ההדמיה ממוקדת בחלון תרגול קצר.

## Interactive Brokers
הפעילו Client Portal Gateway מקומי בפורט 5000 והתחברו לחשבון Paper בדפדפן של IBKR. לחצו בעיר על בדיקת חיבור IBKR. הבדיקה קוראת בצד השרת את iserver/auth/status. השתמשו בתעודה מהימנה לשער המקומי. לתעודה פרטית אפשר להפנות את NODE_EXTRA_CA_CERTS לקובץ ה-CA המהימן לפני הפעלת השרת. אין לשמור סודות במאגר.

לפני מסחר דרך הברוקר נדרשים אימות הרשאות לחוזים עתידיים ונתוני CME, בחירת חוזה לפי פקיעה, חיבור נתוני חשבון וביצועים, בדיקות הזמנה וביטול בחשבון Paper והתאמת הוראות אחרי ניתוק. מצב כסף אמיתי נעול. התקציב בסימולציה מודד חשיפה נומינלית ואינו מייצג את דרישת הביטחונות של IBKR.

[מדריך IBKR](https://www.interactivebrokers.com/campus/trading-lessons/launching-and-authenticating-the-gateway/) · [מפרט MNQ](https://www.cmegroup.com/markets/equities/nasdaq/micro-e-mini-nasdaq-100.html)

## משרד הסקאלפינג
מסך הפתיחה מציג רובע איזומטרי עם משרד ובנק. לחיצה על בניין המשרד פותחת את קומת המסחר. כפתור החזרה מחזיר לעיר ומשהה את ההדמיה.

במשרד שישה סוכנים מבוססי כללים:
- סורק שוק — שינויי מחיר ונפח בצעדי 15 שניות.
- סקאלפ מומנטום — שינוי מחיר על פני דקה.
- סקאלפ פריצה — פריצה מעל טווח שתי דקות עם נפח עולה.
- סקאלפ התאוששות — חזרה כלפי מעלה לאחר התרחקות מהממוצע.
- מנהל סיכונים — תקרת חשיפה ומגבלות חשבון.
- סוכן ביצוע — ביצועים חלקיים ויציאות.

הגדרות המחקר הראשוניות הן יעד של 4 נקודות, עצירה של 3 נקודות ותקרת זמן של 45 שניות מהביצוע הראשון. התנאים נבדקים בכל צעד, ולכן מחיר היציאה בפועל יכול לעבור את הסף. המחקר כולל כניסות קנייה בלבד. בדיקות הסקאלפינג משתמשות בחמישה תרחישים סינתטיים נפרדים. תוצאות מחקר אינן הוכחה לרווחיות. נתוני ההדמיה הישנה נשמרים בנפרד בדפדפן.

לאחר עדכון קבצי השרת יש להפעיל אותו מחדש.

## הרובע העתידני
העיר כוללת משרד זכוכית ובנק עגול עם כיפה ועמודים מוארים. לחיצה על כל מבנה פותחת אותו. במשרד מוצגות שש עמדות עבודה עם דמויות. לחיצה על דמות או עמדה פותחת מסוף עם גרף נרות וכרטיס סוכן. אפשר גם לבחור סוכן מהתפריט שבראש קומת המסחר. סגירה או Escape מחזירים לחדר. מסך הבנק מציג את החשיפה המקומית, הגדרות הסיכון והוראות הכנה לנתוני שוק ולחדשות.

### הכנות לחיבור אמיתי
1. בחשבון IBKR הפעילו חשבון Paper ואמתו הרשאות לחוזים עתידיים ולנתוני CME עבור MNQ דרך API. בחירת מנוי תלויה בהרשאות המשתמש ובסיווגו.
2. בחשבון Paper אפשר להשתמש בנתוני זמן אמת בהתאם למנוי ולהגדרות השיתוף. יש לאמת את סוג הנתונים ואת חוזה הפקיעה.
3. נדרש עדיין לממש ולבדוק מתאם שמזרים את הנתונים לסוכנים ומסנכרן הוראות, ביצועים ויתרות מול Paper. בדיקת השער הקיימת אינה מתאם מסחר. לחיבור דרך TWS API יש להפעיל TWS או IB Gateway.
4. לחדשות אפשר לחבר ספקים הכלולים במנויי API של IBKR, ובנוסף פידים רשמיים של Federal Reserve ו-BLS. יש לשמור מקור, קישור, זמן פרסום וזמן קליטה, ולכבד את רישיון הספק בשמירת תוכן. גישה למקורות מידע אינה מאמנת אוטומטית את הסוכנים. נדרש תהליך נפרד להפקת תכונות ובדיקת השפעתן על אסטרטגיה.

## מסוף השוק
בעמדת סוכן אפשר לצפות בנרות BTC/USDT ו־ETH/USDT של Bybit Spot בטווחי דקה, חמש דקות ורבע שעה, או לבחור בנתוני התרגול המקומי של MNQ. חיבור המחירים לקריאה בלבד. אין צורך בחשבון Bybit או במפתח לצפייה הציבורית. שם המקור, זמן העדכון ומצב החיבור מוצגים במסוף. הזמינות תלויה בגישה של המחשב לשירות ולמדיניות האזורית שלו.

השרת מבקש היסטוריית נרות מה־API הציבורי של Bybit והדפדפן מתחבר לעדכוני נרות. במצב ניתוק ניתן להציג הקלטת OHLCV אמיתית, שסופקה באמצעות חיבור Bybit בזמן בניית הגרסה. הקלטות מתוארכות ומסומנות בנפרד. הצפייה בקריפטו אינה משנה את מכשיר ההדמיה של הסוכנים.

דסק ETH מבצע הוראות בחשבון Bybit Demo לאחר הגדרה מקומית של מפתח דמו. לצפייה בחוזה MNQ אמיתי יש קישור ייעודי ל־TradingView; הזרמת נתוני CME אל הסוכנים מצריכה חיבור בעל הרשאות מתאימות.

למחקר מניות אפשר לפתוח את Finviz מהבנק. API וייצוא רשמיים זמינים במסלול Elite. החוזים מוצגים ב־Finviz בהשהיה של 20 דקות גם ב־Elite.

## דסק ETH בחשבון Bybit Demo

1. נכנסים ל־Bybit, עוברים ל־Demo Trading, ומתוך תפריט API של הדמו יוצרים מפתח מערכת (HMAC) עם קריאה והרשאת מסחר Spot. אין צורך בהרשאות משיכה או העברה. משאירים בארנק הדמו USDT פנוי.
2. ב־Windows לוחצים פעמיים על **הגדרת Bybit Demo.cmd** ומזינים את המפתח והסוד בחלון המקומי. הקלט מוסתר והערכים נשמרים מוצפנים עם DPAPI למשתמש Windows הנוכחי, תחת LocalAppData בתיקיית TradingCity/BybitDemo. אין להעלות את תוכן התיקייה למאגר. בשרת אחר אפשר להגדיר את משתני הסביבה BYBIT_DEMO_API_KEY ו־BYBIT_DEMO_API_SECRET למשתמש שמפעיל את Node. המפתחות זמינים לשרת בלבד.
3. מפעילים את השרת עם `node server.mjs` ופותחים [דמו ETH](http://127.0.0.1:4173/#eth). לוחצים על **בדיקת חיבור הדמו**, בודקים את היתרות, בוחרים תקציב, תקרת פוזיציה וסף הפסד יומי ב־USDT, ואז לוחצים על **הפעלת הדסק בדמו**. אין צורך להפעיל מחדש את השרת אחרי שימוש בקובץ ההגדרה.
4. במצב ידני יש לאשר גם קנייה וגם מכירה. במצב אוטונומי השרת רשאי להגיש הוראות לפי האות והמגבלות, גם כשהדפדפן סגור, כל עוד השרת פועל. הפעלה מחדש של השרת דורשת חיבור, סנכרון והפעלה מחדש של הדסק.

הסוכנים מנתחים נרות דקה סגורים ממחירי הספוט הציבוריים. הסריקה בודקת מומנטום, פריצת טווח וחזרה לממוצע, ומאפשרת כניסה אחת לנר לכל הדסק. הרכישה שומרת מרווח הוצאות של 0.5% בתוך התקציב. פקודות מוגבלות במחיר ובזמן (IOC) נשלחות ל־ETHUSDT Spot בדמו בלבד, ללא מינוף. מנהל היציאה בודק יעד 0.35%, עצירה 0.25% או החזקה של חמש דקות. מחיר סגירה בפועל תלוי בביצוע בבורסה. הדסק מציע למכירה רק ETH שביצועי הקנייה שלו נרשמו בדסק, ומפחית עמלות ממטבע הגבייה.

יומן ההוראות והביצועים נשמר מקומית בנפרד מהמפתח. רווח יומי נמדד מתחילת יום UTC. הפסד ממומש מקטין את התקציב הזמין. עצירה חוסמת משלוחים חדשים, מבקשת לבטל הוראות של הדסק ומשאירה את הפוזיציה מוצגת. אובדן תשובה אחרי שליחה נועל את הדסק. יש להתחבר שוב וליישב את ההוראה לפי המזהה המקורי. אם ההוראה אינה ניתנת לאימות, נדרשת בדיקה בחשבון עצמו. הוראות דמו ב־Bybit נשמרות לשבעה ימים.
