# עיר הסוחרים
עיר מסחר איזומטרית בעברית עבור חוזי MNQ. הנתונים סינתטיים והסוכנים מפעילים כללי החלטה.

## הפעלה
עם Node.js 22 ומעלה, הריצו בתיקייה `node server.mjs` ופתחו http://127.0.0.1:4173. אין תלויות להתקנה. לבדיקות הריצו `node --test engine.test.mjs`.

לחצו על הפעלה. כאשר מופיעה הצעה לחצו על אישור הצעה והמשיכו בהפעלה. לחיצה על עסקה מציגה את מסלול ההחלטה והביצועים. עצירת חירום שומרת את הפוזיציה הפתוחה ומבטלת את יתרת ההוראה המדומה. יום חדש שומר עותק מהיום הקודם בדפדפן. ההדמיה ממוקדת בחלון תרגול קצר.

## Interactive Brokers
הפעילו Client Portal Gateway מקומי בפורט 5000 והתחברו לחשבון Paper בדפדפן של IBKR. לחצו בעיר על בדיקת חיבור IBKR. הבדיקה קוראת בצד השרת את iserver/auth/status. השתמשו בתעודה מהימנה לשער המקומי. לתעודה פרטית אפשר להפנות את NODE_EXTRA_CA_CERTS לקובץ ה-CA המהימן לפני הפעלת השרת. אין לשמור סודות במאגר.

לפני מסחר דרך הברוקר נדרשים אימות הרשאות לחוזים עתידיים ונתוני CME, בחירת חוזה לפי פקיעה, חיבור נתוני חשבון וביצועים, בדיקות הזמנה וביטול בחשבון Paper והתאמת הוראות אחרי ניתוק. מצב כסף אמיתי נעול. התקציב בסימולציה מודד חשיפה נומינלית ואינו מייצג את דרישת הביטחונות של IBKR.
